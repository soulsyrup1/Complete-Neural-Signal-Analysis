**Complete Neural Signal Analysis Toolbox** is an open-source research toolbox for EEG analysis, neural signal processing, biomedical signal processing, signal analysis, signal processing, multichannel time-series analysis, nonlinear time-series analysis, spectral analysis, entropy analysis, complexity measures, dynamical systems, chaos theory, fractal analysis, multifractal analysis, topology, topological data analysis, graph theory, network neuroscience, geometry, manifolds, curvature analysis, quantum-inspired analysis, information-geometric analysis, and neural-state manifold dynamics.

This repository is designed for researchers, developers, students, computational neuroscientists, AI researchers, signal-processing engineers, neurotechnology builders, biomedical signal processing researchers, brain-computer interface researchers, government research groups, academic labs, open-source scientific software users, and anyone working with EEG data, neural signals, brain-signal analysis, biosignals, biomedical time-series data, nonlinear dynamics, feature extraction, and advanced mathematical methods for neural systems.

The included `neuro_signal_GUI_v0_9_1/` interface is designed for users with no coding knowledge. It provides a no-code graphical workflow for neural signal analysis and is built to accept a wide range of neural signal file formats, folder structures, table layouts, multichannel recordings, time-series datasets, EEG files, and custom neural signal data structures.

Browse the folders to see all the tools.

---

## Quick Start

### Option 1: Use the No-Code GUI

The fastest way to begin is with the GUI:

1. Open the `neuro_signal_GUI_v0_9_1/` folder.
2. Launch the GUI using the included launcher or Python entry point.
3. Load a neural signal file, EEG file, multichannel recording, time-series dataset, table, folder structure, or custom neural signal data structure.
4. Choose the analysis workflow you want to run.
5. Export or review the generated results.

The GUI is intended for users who want neural signal analysis without coding knowledge.

### Option 2: Browse the Toolbox Folders

Each folder contains methods for a different analysis area, including spectral analysis, entropy, nonlinear dynamics, fractal analysis, topology, geometry, quantum-inspired analysis, and neural-state manifold dynamics.

### Option 3: Use the Repository as Research Software

Researchers can use this repository as a reference toolbox, method library, educational resource, or starting point for reproducible neural signal analysis, EEG analysis, biosignal analytics, computational neuroscience, and AI-assisted biomedical signal processing.

## No-Code Neural Signal GUI

`neuro_signal_GUI_v0_9_1/` is the graphical interface for the toolbox.

It is designed to make neural signal analysis accessible to users who do not write code. The GUI accepts many neural signal file formats and data structures, including flexible folder structures, table layouts, multichannel recordings, time-series datasets, EEG files, biosignal files, and custom neural signal data structures.

The GUI is useful for:

- No-code neural signal analysis
- GUI-based EEG analysis
- Neural signal analysis without coding
- Neural signal file format support
- Flexible neural signal data structure support
- Beginner-friendly neural signal processing
- Research workflows for users without programming experience
- Fast exploration of neural signal, EEG, biosignal, and time-series data

## Repository Structure

| Folder / Area | Description |
|---|---|
| `Data_Loading_and_Variable_Assigning_files/` | Data loading, variable assignment, signal preparation, and analysis setup |
| `Dynamical_Systems/` | Dynamical systems, nonlinear dynamics, chaos, Lyapunov methods, attractor reconstruction, nonlinear coupling, and chaos control |
| `Entropy/` | Entropy measures, complexity measures, multiscale entropy, sample entropy, approximate entropy, transfer entropy, entropy rate, and feature extraction |
| `Fractal/` | Fractal analysis, fractal dimension, multifractal analysis, DFA, MFDFA, Hurst exponent, and wavelet-fractal analysis |
| `Geometry/` | Manifolds, manifold learning, state-space geometry, Riemannian geometry, SPD manifolds, covariance manifolds, geodesics, curvature, and tangent-space analysis |
| `Library/neural_signal_analysis/` | Core reusable neural signal analysis library code |
| `Neural Net_files/` | Neural network, AI, machine learning, and computational modeling files |
| `Quantum Analysis/` | Quantum-inspired, quantum-like, density-matrix, von Neumann entropy, quantum coherence, Hermitian matrix, and positive-semidefinite analysis |
| `Spectral Analysis/` | Spectral analysis, PSD, Welch method, FFT, Lomb-Scargle, periodogram, wavelet transform, STFT, band power, coherence, and functional connectivity |
| `Topology/` | Topology, topological data analysis, persistent homology, graph theory, weighted networks, modularity, small-world networks, graph metrics, and network neuroscience |
| `neuro_signal_GUI_v0_9_1/` | No-code GUI tools for neural signal analysis workflows. The GUI is designed to accept a wide range of neural signal file formats and data structures without requiring coding knowledge. |
