    SpeedMouse Workbench

    Use the original SpeedMouse workbench as the interactive browser workbench. Our backend converts, computes large/offline features, writes SpeedMouse data.json, and opens SpeedMouse with variable electrode names/counts intact.

    SpeedMouse Live Replay

    This streams sample-major JSON frames into the SpeedMouse live panel. It uses the same variable-electrode metadata from channels.csv.

    SpeedMouse Comparison

    Builds one SpeedMouse data.json per recording, a comparison manifest, and a session ZIP. Feature-level comparison is safe across different electrode counts.
