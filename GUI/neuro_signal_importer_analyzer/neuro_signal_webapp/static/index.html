    NeuroMouse analysis options

    Large files are analyzed offline by the Python backend, then opened in the original NeuroMouse workbench. The raw converted signal is still preserved.

    NeuroMouse Workbench

    Use the original NeuroMouse workbench as the interactive browser workbench. Our backend converts, computes large/offline features, writes NeuroMouse data.json, and opens NeuroMouse with variable electrode names/counts intact.

    NeuroMouse Live Replay

    This streams sample-major JSON frames into the NeuroMouse live panel. It uses the same variable-electrode metadata from channels.csv.

    NeuroMouse Comparison

    Builds one NeuroMouse data.json per recording, a comparison manifest, and a session ZIP. Feature-level comparison is safe across different electrode counts.
